# 📐 Discrete Mathematics Toolkit

Interactive Problem Solver & Visualizer built with Python + Streamlit.

## Modules
- Logic & Predicate Calculus
- Sets & Relations
- Boolean Algebra
- Graph Theory
- Trees & Minimum Spanning Tree
- Graph Coloring / Exam Timetable

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python -m streamlit run app.py
```
